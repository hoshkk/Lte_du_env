# RX 점검 (Android) — RTL-SDR V4 장비 리버스 / 불요파

휴대폰 OTG에 RTL-SDR Blog V4를 연결해 KT LTE 기지국 RX(상향) 대역을 현장에서 점검하는 앱입니다.
드라이버부터 처음부터 작성했고 C/NDK 없이 Kotlin만 사용합니다.

## 측정 모드

| 모드 | 용도 | 결과 |
|---|---|---|
| **장비 리버스** | 장비 RX 경로(커플러·모니터 포트)의 상향 잡음·간섭 | 채널 전력, PSD(dB/MHz), **1 MHz 블록별 PSD**(중앙값 대비 튀는 블록 = 협대역 간섭 의심), **기준 대비 상승**(야간 등 정상 시 저장한 기준과 비교) |
| **불요파** | 안테나 쪽 RX 대역 주변 불요 발사 | 노이즈 플로어, 플로어+임계 이상 피크 목록(주파수/레벨/폭/RX 대역 내외), Max Hold |

대역 프리셋 (RX 센터는 현장 확인값, 사이트별 확인 필요):

| 프리셋 | 채널 | 장비 리버스 Span | 불요파 범위 |
|---|---|---|---|
| B8 RX | 909.3 MHz / 10 MHz | 15 MHz | 894.3–924.3 MHz (B8 DL 925 MHz 직전까지) |
| B3 RX 20M | 1745.0 MHz / 20 MHz | 25 MHz | 1725–1765 MHz |
| B3 RX 30M | 1750.0 MHz / 30 MHz | 31 MHz | 1720–1766 MHz (V4 상한) |

## 속도를 위해 한 것

스윕 시간의 대부분은 구간마다 튜너를 옮기는 USB 제어 전송입니다(휴대폰에서 1회 약 2 ms).
이 앱은 구간 이동 시 전송 수를 줄였습니다.

| | 일반 드라이버 순서 | 이 앱 (고속 동조) |
|---|---|---|
| I2C 리피터 열기/닫기 | 매 이동 4회 | 0회 (계속 열어 둠) |
| PLL 레지스터 0x14–0x16 | 3회 | 1회 (I2C 버스트) |
| 값이 같은 레지스터(VCO 전류, 분주비, mux) | 매번 전송 | 생략 |
| 고정 대기(sleep) | 수 ms | 없음 (PLL 잠금 확인 후 FIFO 리셋 + 2048샘플 폐기) |
| **구간당 제어 전송** | 13–15회 | **약 9회** (동조 7 + FIFO 리셋 2) |

- 기록되는 값(주파수, PLL 설정, 잠금 확인)은 일반 순서와 같습니다. 단위 테스트가 두 방식의 최종 튜너 레지스터가 동일한지 비교합니다.
- 설정의 **고속 동조**를 끄면 참고 드라이버와 같은 순서로 동작합니다. 현장에서 A/B로 비교할 수 있습니다.
- 화면 하단에 스윕 시간, 구간당 USB 제어 횟수가 표시됩니다.

또 구간마다 FFT를 여러 장 평균(기본 장비 리버스 16, 불요파 4)해서 트레이스가 잔디처럼 튀지 않습니다.
평균 1장은 0.1 ms 수준이라 속도에 거의 영향이 없습니다.

## 설치

1. GitHub → Actions → **Android APK** → 최신 실행 → `rx-check-debug-apk` 다운로드
2. 압축 해제 후 `app-debug.apk` 설치 (출처를 알 수 없는 앱 허용 필요)
   - 디버그 빌드는 빌드마다 서명이 달라, 업데이트 시 기존 앱 삭제 후 설치해야 할 수 있습니다.
3. 동글 연결 → 앱 실행 → **측정 시작** → USB 권한 허용

동글 없이 **데모** 버튼으로 화면을 먼저 볼 수 있습니다(시뮬레이터).

## 사용 순서 (장비 리버스)

1. 모드 **장비 리버스**, 대역 프리셋 선택, 이득을 낮게(기본 2/15)
2. 트래픽이 적은 시간에 측정 → **현재를 기준으로 저장**
3. 문제 시간대 측정 → 채널 전체 상승(dB)과 상승한 1 MHz 블록 확인
4. 커플러 손실 등을 알면 **Offset**에 입력 (표시값만 보정, 교정 dBm 아님)

기준은 Span·RBW가 같은 측정에만 적용됩니다(다르면 자동으로 무시).

## 한계

- 레벨은 dBFS 상대값입니다. 전파법 적합성 판정용 측정기가 아닙니다.
- 8-bit 동글이라 동시 다이나믹레인지가 약 45 dB입니다. 강한 신호 옆의 아주 낮은 불요파는 동글 자체 왜곡일 수 있습니다.
  이득을 낮춰도 dBc가 그대로인지 확인하세요.
- 수신 범위 24–1766 MHz (V4). B3 DL, 2.1 GHz, 3.5 GHz는 측정할 수 없습니다.
- 실제 하드웨어 검증 전입니다. 단위 테스트는 레지스터 모형(fake USB)과 시뮬레이터로 동작을 확인한 것입니다.

## 구조

```
android/
  core/   순수 Kotlin (JVM 테스트 가능)
    rtl/       RTL2832U + R820T/R828D(V4) 드라이버, USB 제어 계층
    dsp/       FFT, 평균 파워 스펙트럼
    sweep/     스윕 계획(구간 75% 사용), 스윕 엔진
    analysis/  채널 전력, 블록 PSD, 피크 검출, 모드별 판정
    sim/       데모/테스트용 시뮬레이터
  app/    Android (Compose UI, USB 권한/연결, 기준 저장, CSV 공유)
```

로컬 빌드: Android SDK가 있는 PC에서 `cd android && ./gradlew :core:test :app:assembleDebug`

드라이버 레지스터 값과 초기화 순서는 Apache-2.0 라이선스의 webrtlsdr를 참고했습니다. [THIRD_PARTY.md](THIRD_PARTY.md) 참고.
